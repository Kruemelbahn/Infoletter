# Infoletter
Krümelbahn-Info sind Informationen zu bestimmten Themen im Umfeld meiner Modellbahn oder auch der großen Eisenbahn.<br>
Es gibt Krümelbahn-Info in den Kategorien<br>
 <li>Allgemein</li>
 <li>Modellbahn (bzw. Modellbau allgemein)</li>
 <li>Solingen</li>
<br>
Krümelbahn-Info erscheinen bei Bedarf, Wünsche zu Themen sind willkommen.
